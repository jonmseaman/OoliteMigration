## History

Phases 0–4 are done. Their phase docs, reports, stories and the 69 ADRs were removed from the tree
on 2026-10-28 and are kept under the git tag `archive/phase-0-4-docs`
(`git show archive/phase-0-4-docs:docs/<path>`). Mentions of `ADR-NNNN` or bead ids (`oo-xxxx`)
in code, tests and notes point there. They are history, not rules: don't look them up unless a
task is specifically about why something was done.

New decisions go in the phase doc they belong to.
