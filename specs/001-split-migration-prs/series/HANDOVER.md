## Anchors

- Series base: upstream `49a5eb9fc` (`series/000-upstream-base`, a Git Town perennial branch).
- End: the fork's `develop` at `3aa8d65e8`, outside the exclusions below.
- Format: clang-format 22.1.8, style from `49a5eb9fc`.

- `.zed/**`: editor settings for the fork's own setup.
- `.vscode/**`: editor settings for the fork's own setup.
- commit `3aa8d65e8` (reverted): the fork's CI filter (push builds only for master and develop).
