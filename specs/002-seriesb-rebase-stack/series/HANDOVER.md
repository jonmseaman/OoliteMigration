## Git Town

The stack's lineage is local configuration (`git config --get-regexp git-town-branch`: each branch's `parent` and `branchtype`); pushing does not carry it, and renaming a branch with the series tool moves it. The parents are `observed` and the steps `prototype`, so `git town sync` never pushes them: push with the commands above. `git town branch` shows the stack.
