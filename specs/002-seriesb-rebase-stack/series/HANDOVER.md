## Git Town

The stack's lineage is local configuration (`git config --get-regexp git-town-branch`: each branch's `parent` and `branchtype`); pushing does not carry it, and renaming a branch with the series tool moves it. The parents are `observed` (they follow upstream's PRs and are never pushed by Git Town); the steps are `feature` branches, so a bare `git town sync --stack` pushes them, without a lease. For the first push of the rebuilt steps use the commands above. `git town branch` shows the stack.
