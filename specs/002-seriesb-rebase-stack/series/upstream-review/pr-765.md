- `.github/workflows/build-all.yaml` and `test_builds.yaml`: the MSYS2 setup input and the step `env` use `MSYSTEM: UCRT64` instead of lower-case `msystem` (the lower-case env var did not select UCRT64).
- `test_builds.yaml` Windows job: drops the `robinraju/release-downloader` step that fetched `oolite_windeps_build` assets (`install_deps.sh` downloads them itself).
- `test_builds.yaml` Windows test step: on failure, prints `ntldd -R oolite.exe` from the build directory and exits 1.
- `ShellScripts/Windows/install_deps.sh`: `jq` moves to the `pacman -S` line; `curl` and `ntldd` are added to `pacboy -S`.
- `ShellScripts/Linux/build_gnustep.sh`: new libobjc2 and libs-base pins.
