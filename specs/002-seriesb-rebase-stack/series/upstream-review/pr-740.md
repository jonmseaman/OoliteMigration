# Upstream #740: Remember last saved game and go to it when loading commander

**Upstream:** mcarans, merged 2026-09-15 as `75cf78f51` · **In the stack:** base (below the conversion)
**Verdict:** Ported correctly

## What the PR changes
- `-setLastsaveName:` also writes the name to the user defaults key `last_savename`.
- Player set-up (`-setUp`/reset) no longer resets the last save name to `PLAYER_DEFAULT_NAME`; it
  reads `last_savename` from the defaults and uses it when present. The load screen's existing
  highlight of the last save name therefore lands on the last saved game across runs (fixes
  issue #710).
- Removes the macOS AppKit open/save panels (`-loadPlayerWithPanel`, `-savePlayerWithPanel`) and
  the `USE_CUSTOM_LOAD_SAVE_ON_MAC_DEBUG` / `OOLITE_USE_APPKIT_LOAD_SAVE` /
  `OO_USE_APPKIT_LOAD_SAVE_ALWAYS` / `OO_USE_CUSTOM_LOAD_SAVE` macros: the in-game load/save screens
  are used on every platform and the `GUI_SCREEN_LOAD`/`SAVE`/`SAVE_OVERWRITE` cases in
  `PlayerEntityControls` are unconditional.
