## What the PR changes
The branch is an older #768 copy (29 commits, patch-equivalent to the stack's: `git cherry HEAD refs/review/pr772 52117591f` marks 28 as already applied) plus 21 commits of its own (`0701f8a17..12c39549e`, 22–26 Oct):

- `GameController.m`: deployment builds also run the JS leak check at exit when a debug console is connected (previously only `#ifndef NDEBUG`).
