# Upstream #748: Fix includes so that include sorting in clang-format doesn't break anything

**Upstream:** mcarans (Mike), merged 2026-09-23 as `0a8207ead` (squash) · **In the stack:** base; include order kept to 016, maths headers reworked at 018, `test_OOOpenGLOnly` and `test_OOMathsHeaders` added, `OOOpenGLOnly.h` LINUX fix at 024 (`380ce2b47`)
**Verdict:** Ported correctly

## What the PR changes

68 files, +103/-164. Preparation for #749's include sorting:

- Headers that relied on being included after something else now include what they use and get
  `#pragma once` (entity, scripting, texture, sound, joystick headers; `NSFileManagerOOExtensions.h`
  includes `OOFoundation.h` instead of `<Foundation/Foundation.h>`). Matching redundant includes are
  dropped from the `.m` files.
- Maths headers: the `INCLUDED_OOMATHS_h` guard and its "Do not include X.h directly" `#error`s go;
  each of `OOVector.h`, `OOHPVector.h`, `OOMatrix.h`, `OOBoundingBox.h`, `OOFastArithmetic.h`
  includes its own dependencies (some gain `#pragma once`; `OOQuaternion.h`, `OOMatrix.h`,
  `OOTriangle.h`, `OOVoxel.h` get no guard).
- `OOMATHS_STANDALONE` and `OOMATHS_OPENGL_INTEGRATION` are removed and their "on" branch kept:
  `OOScalar` is always `GLfloat`, `OOOpenGL.h` always included, the GL macros
  (`GLVertexOOVector`, `GLTranslateOOHPVector`, `OOMatrixLoadGLMatrix`, `GLUniformMatrix3`), random
  vectors/quaternions, `kZeroBoundingBox`, `OOVoxel.h`, `OOTriangle.h`, `OOBoundingBox.h` and
  `legacy_random.h` always compiled.
- `OOOpenGLOnly.h`: the Apple `OpenGL/` branch, the `OOLITE_SDL` inference, the `#error unknown
  target` and `#define NO_SDL_GLEXT` are removed; only the SDL path remains, with `#pragma once`.

No runtime behaviour changes; the build configurations upstream ships already took the
"integration on, not standalone" branches.

## Findings

None. The fork goes further than upstream (every maths header guarded; `OOMathsBase.h` holds the
shared typedefs), which is compatible with #748's intent.

## Why this verdict

#748 changed only what headers include and which build-configuration branches exist. At HEAD the
removed configuration macros are gone and tested absent, the kept branches are unconditional, the
OpenGL header is SDL-only without `NO_SDL_GLEXT`, and headers compile standalone. The one
difference in `OOOpenGLOnly.h` adds a condition for plain C++ units on Linux and does not undo
anything #748 did.
