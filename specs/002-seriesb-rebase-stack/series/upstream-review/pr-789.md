- Page 3: layout and emphasis changes (Combat Rank, Legal Status tables, "?" bold).
- Page 5 (Expansion Pack Manager): the list-colour legend is drawn on black with yellow, white,
  cyan, orange, brown, gray, red and blue.
- `common.typ`: `section-header` cells are centred.

## Findings

1. Not a fork issue: the legend uses its own hex values for the colours (cyan `008B8B`, brown
   `7B3D00`). The game draws cyan as (0, 1, 1) and brown as (0.6, 0.4, 0.2) (`OOColor.cpp`),
   the same as upstream. This is an artistic choice in the upstream doc, and the fork reproduces it
   unchanged.
2. Not a fork issue: page 1 says Pg Up zooms the chart in and Pg Dn zooms it out. The defaults are
   `n_key_map_zoom_in = gvPageDownKey` and `n_key_map_zoom_out = gvPageUpKey`
   (`PlayerEntityControls.cpp`), the same as upstream's `.m`. Whatever the in-game effect, it
   matches upstream; I did not check whether the doc's wording is right.

## Why this verdict

#789 is the stack's base commit, and the fork has not changed any documentation file since. Every
behaviour the updated pages describe has the same defaults and logic in the C++ code as in
upstream's Objective-C: key bindings, Esc-twice for the escape pod, and the expansion manager's
colours. Two unit tests pin the colours.
