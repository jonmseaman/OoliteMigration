# Upstream #774: Fix blank game window after splash on Linux/X11 (#773)

**Upstream:** stickleprojects, merged 2026-10-29 as `7f5ad9e0b` · **In the stack:** base (below the conversion)
**Verdict:** Ported correctly

## What the PR changes
- When the game starts windowed after a splash, `-endSplashScreen` replaces the borderless splash
  window with a new window created hidden, resizable and centred at the game size
  (`SDL_WINDOW_OPENGL | SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIDDEN | SDL_WINDOW_HIGH_PIXEL_DENSITY`),
  destroys the splash window, then shows the new one. Previously it hid, resized and re-showed the
  splash window.
- `-createWindowWithSize:` reuses the existing `glContext` (makes it current on the new window)
  instead of creating a second one, and re-makes it current after `SDL_GetWindowSurface()` (which
  can leave SDL's renderer context current). Both `SDL_GL_MakeCurrent` calls exit on failure.
- `-endSplashScreen` makes `glContext` current again after destroying the old window.
- `SDL_SetWindowResizable`/`SDL_SetWindowBordered` are only called when the window is not replaced.
- The unused `splashWindow` ivar is removed.
