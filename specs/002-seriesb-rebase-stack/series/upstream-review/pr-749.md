## What the PR changes

Fixes upstream issue #572. Adds `.clang-format` (`BasedOnStyle: WebKit`, nothing else) and runs
clang-format over every `.h/.c/.m/.cpp/.hpp/.mm` under `src`, 514 files, with no manual edits
(PR text; the author notes the pure C files were missed at first).

Checked for non-whitespace changes:

- 288 of the 514 files differ once all whitespace is removed. Removing `#include`/`#import` lines
  as well leaves 65; removing line-continuation backslashes too leaves **0**. A token-level diff
  (identifiers and punctuation, includes and `\` excluded) of all 65 against `f52cca672^1` is empty.
  So apart from layout, #749 changes only (a) the order of include lines and (b) where
  macro-continuation backslashes fall.
- Include multisets differ in three files, each a duplicate `#import` removed by clang-format's
  sorting: `#import "OOPlanetEntity.h"` in `PlayerEntityLegacyScriptEngine.m`,
  `"OOStringParsing.h"` in `OOCheckShipDataPListVerifierStage.m`, `"OOShipGroup.h"` in
  `OOJSShipGroup.m`. `#import` already ignored the second copy.
- Include reordering within blocks is the change #748 prepared for; upstream built and ran after it
  (PR text).
- Vendored files were reformatted too (`miniz.c/.h`, `tinyexr.h`, `stb_image_write.h`,
  `MiniZip/unzip.c`), again with no token change.
- The bitwise `|` key reads in `PlayerEntityControls.m` (e.g. `[self checkKeyPress:a] |
  [self checkKeyPress:b] | ...`, seven sites, base `148575aab` lines 2371, 2411, 2504, 2551, 2595,
  4342, 4383) are unchanged by #749 except for spacing; clang then flags them as `|` on bools.

## Tests

The CI clang-format job (`.github/workflows/build-all.yaml:16-29`) rejects unformatted code in
`src`. Nothing in `tests/` pins the key-read helper.

## Findings

1. Deviation by design: the fork's style is Google, not upstream's WebKit. Merging the stack into
   upstream changes upstream's `.clang-format` and the layout of every file. This is step 023's
   stated purpose ("Reformat with Google-style clang-format (optional)",
   `specs/002-seriesb-rebase-stack/series/pr/023-google-style-format.md`); whether upstream takes it is upstream's call.
2. The `|`-to-`AnyKeyPressed` change keeps upstream's semantics (all keys read, result true if any
   is down) and removes the bool-`|` warning without suppressing it.

## Why this verdict

Upstream #749 changed no tokens beyond include order, duplicate imports and continuation
backslashes, and the fork keeps all of that at the token level. The deviation is the style itself:
the fork replaced WebKit with Google at step 023 on purpose, and rewrote the seven `|` key reads
into a helper with the same effect.
