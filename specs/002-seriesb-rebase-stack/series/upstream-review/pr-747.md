# Upstream #747: Common SDL3 stringToClipboard; Linux mouse control in line with Windows

**Upstream:** mcarans, merged 2026-09-23 as `54cf49a7c` · **In the stack:** base (below the conversion)
**Verdict:** Ported correctly

## What the PR changes
- `-stringToClipboard:` uses `SDL_SetClipboardText` on every platform (logs
  `stringToClipboard.failed` with `SDL_GetError()`), replacing the Win32 clipboard code and the
  Linux no-op stub.
- `-getDisplayDimensions:height:`, `-isRunningOnPrimaryDisplayDevice` and
  `-grabMouseInsideGameWindow:` are no longer Windows-only; the Linux stubs ("always primary",
  "grab does nothing") go. The options screen's off-primary-display size check is unconditional.
- Mouse control (`M`) calls `resetMouse` and, with `grab-mouse-on-mouse-control`, grabs the mouse on
  every platform, and releases the grab when turned off (the `#if OOLITE_GNUSTEP` guards go).
- The OXZ manager no longer copies the info URL to the clipboard when the info page opens. A new
  key `key_oxzmanager_copyurl` (default `c`) copies it: on the info page, the URL that page showed
  (stored lowercased by `-setOXPURL:`); on a pick list, the selected pack's `information_url`.
- Resources: the key in `keyconfig.plist` and `keyconfig2.plist`, its description
  `oolite-keydesc-key_oxzmanager_copyurl`, and reworded OXZ manager help strings ("Info URL: %@" etc.).
