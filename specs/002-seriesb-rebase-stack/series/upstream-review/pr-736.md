# Upstream #736: Wrap clang pragma in `#ifdef __clang__`

**Upstream:** mcarans (Mike), merged 2026-09-07 as `643185345` (squash) · **In the stack:** base; the three files it touches were retired by the conversion (008, 016)
**Verdict:** Superseded

## What the PR changes

Build-only. It wraps the `#pragma clang diagnostic push / ignored
"-Wobjc-protocol-method-implementation" / pop` that #734 added in `#ifdef __clang__`, so GCC stops
warning about an unknown pragma, in:

- `src/Core/NSBundle+Override.m`
- `src/Core/NSUserDefaults+Override.m` (the closing guard is spelled `#ifdef __clang_`, one
  underscore short, so under Clang the `pop` is never emitted; harmless at the end of the file)
- `src/Core/OOCocoa.m` (around `-[NSObject description]`)

No runtime behaviour changes.
