# Upstream #735: Replace more Win32 code

**Upstream:** mcarans, merged 2026-09-07 as `7c4a6043f` · **In the stack:** base (below the conversion); carried by the `MyOpenGLView` / `PlayerEntity` conversion
**Verdict:** Ported correctly

## What the PR changes
- `-getNativeSize` uses `SDL_GetDisplayUsableBounds` on Windows too (the `GetSystemMetrics` branch
  and the "unknown architecture" branch go).
- `-isRunningOnPrimaryDisplayDevice` compares `SDL_GetDisplayForWindow(window)` with
  `SDL_GetPrimaryDisplay()` (returns NO with no window), replacing `MONITORINFOEX`.
- New `-getDisplayDimensions:height:` (display bounds via SDL); the game-options screen uses it
  instead of `currentMonitorInfo` when not on the primary display. `monitorInfo`,
  `-getCurrentMonitorInfo:`, `-currentMonitorInfo` go.
- `-grabMouseInsideGameWindow:` uses `SDL_SetWindowMouseGrab` instead of `ClipCursor`.
- `-isOutputDisplayHDREnabled` reads `SDL_PROP_DISPLAY_HDR_ENABLED_BOOLEAN` of the primary display
  instead of the `QueryDisplayConfig` walk.
- The GL log prints `SDL_GetWindowPixelFormat` instead of `GetPixelFormat(GetDC(...))`.
- The splash screen no longer restyles/moves the window with `SetWindowLong`/`MoveWindow`.
