# Remove the Objective-C runtime and rename the sources to .cpp

<!-- Written by tools/series/series.py --series seriesb describe. A rerun keeps the four hand-written sections and rewrites the rest. -->

Step 16/28. Replays `series/018-objc-runtime-out`.

## What this changes

- Autorelease pools become `oo::AutoreleaseScope` (`src/oofnd/Ref.hpp`) at upstream's pool sites;
  `OORaiseException`/`OOAssert` throw `oo::Exception` (`src/oofnd/Exception.hpp`), `@try` -> `try`.
- Deletes the last Objective-C support (`OOObject`, `OOConstantString`, `OOWeakReference` with the
  last bridge, `OOWeakSet`, `OOCallByName.mm`, the ObjC queues, the `oofnd/objc` runtime headers);
  remaining `@encode()` strings become literals in generated `src/Core/OOTypeEncodings.h`.
- Renames every `.mm` to `.cpp` (`#import` -> `#include`; macOS-only blocks keep theirs).
  `meson.build`, `clang.ini`, `gcc.ini` drop `objc`/`objcpp`, libobjc2 and every `-fobjc-*` flag.
- Converts #768's remaining Objective-C (engine finalizer and converter, mission reset observer,
  `@catch (id)` handlers; `OOJSReportWrappedException(id)` goes) and its `poc/` harness. Keeps
  #748's include order and #766's legacy-context check and `OOLITE_MACOS` sites.
- New tests: `test_EntityScriptEvents` (8 cases, #780's events) and oofnd
  `test_plist_hdr_brightness_index`.

## Why

Removes the Objective-C compiler and runtime from the build, the point of the series.

## Behaviour changes

None. The equivalences are pinned:
- Exception names, log text and a script's `Native exception: ...` are unchanged. Pinned by `nativeExceptions` in `test_OOJSWaypoint.cpp`.
- Scopes release at upstream's pool drain points. Pinned by `clearCacheReleasesAtTheNearestScopesDrain` in `test_OOTexture.cpp`.
- Type encodings are byte-identical to `@encode()`. Pinned by `typesFromEncodings` in `test_OOShaderUniformMethodType.cpp` and `objectNamesAnsweredWithoutTheObject` in `test_OOEntityCalledByName.cpp`.
