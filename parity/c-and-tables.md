Rule 9: C stays C. These files should be byte-identical to upstream apart from include/guard plumbing.
Checked with `diff --strip-trailing-cr upstream/oolite/src/<f> src/<f>`.

Audited against seriesb/028-upstream-772-tests @ bf01f1b49 on 2026-11-16.

On this commit the port has **no `.c` files**. Commit 48cbd7abf ("Compile the remaining C sources as C++", cherry-picked from f518b81af) renamed all six upstream `.c` files and the former `OOVoxel.c` to `.cpp`, and clang-formatted them. Every file therefore has a large raw diff (whitespace, brace placement, line wrapping). To explain every diff line, each pair was also compared as a comment-stripped token stream (scratch tokenizer, aid only). Every token difference is listed in the Note column and was read in the source. No port `.c` file lacks an upstream counterpart. No upstream `.c` is missing: each one is now the `.cpp` of the same name in the same directory.
